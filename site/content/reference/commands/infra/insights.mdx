## Synopsis

```bash
aigon insights [--coach] [--refresh]
```

## Shortcuts

- `/ai` (slash command) · `aigon ai` (CLI)

## Description

Displays workflow insights — metrics, trends, and recommendations based on your feature history, including trend analysis, cross-agent comparisons, and AI coaching.

## Flags

| Flag | Description |
|------|-------------|
| `--coach` | Enable AI-powered coaching recommendations |
| `--refresh` | Recalculate insights from scratch instead of using cached data |

## Usage

```bash
# View insights
aigon insights

# With AI coaching
aigon insights --coach

# Force recalculation
aigon insights --refresh
```

## Access

- **CLI**: Basic metrics (features completed, cycle time, agent wins) plus trend analysis and coaching with `--coach`
- **Dashboard**: Insights are also available in the dashboard under the "Insights" tab
