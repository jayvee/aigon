## Synopsis

```bash
aigon feedback-create <title>
```

## Shortcuts

- `/afbc` (slash command) · `aigon afbc` (CLI)

## Description

`feedback-create` is a legacy no-op. It prints the deprecation notice and does not create a feedback file. Capture new user/customer input as research with `origin: customer-feedback`.

Use `research-create` for new input and record the customer source in the research frontmatter.

## What it does

1. Prints the deprecation notice
2. Does not create or change a feedback file
3. Directs new input to `aigon research-create`

## Examples

```bash
# Create a feedback item from the CLI
aigon research-create "Export button crashes on Safari"

# From an agent session (agent fills in details after creation)
/aigon:research-create "Dashboard load time regression after deploy"
```

## Capture new feedback

Create research, then add `origin: customer-feedback` plus the reporter and source evidence to its frontmatter and body.
