---
title: Feedback Workflow (Legacy)
description: Migration guidance for retired feedback commands.
---

Feedback commands and the feedback lifecycle are retained only for compatibility. `feedback-create` is a no-op. Capture new user or customer input as research with `origin: customer-feedback`.

## Capture new customer input

```bash
aigon research-create "User login is slow on mobile"
```

Record `origin: customer-feedback`, the reporter/source, and the supporting evidence in the created research topic. Research can then recommend zero or more features through its normal output.

## Existing historical records

```bash
Existing feedback records remain readable for historical traceability. Do not create or triage new records with the legacy commands.
```

## Next steps

Use the [Research workflow](./research-workflow) for investigation and feature recommendations. Legacy records should stay historical rather than being rewritten into a new workflow.
